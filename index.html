What the agent can do

Three focused skills. Two signature features. Built for engineers shipping hard systems work under pressure.

Advanced Feature #1
⬡
Kernel Failure Radar
Maps sparse failure signals — panic text, dmesg snippets, perf anomalies — to likely subsystems. Returns confidence-ranked hypotheses, the three highest-yield probe commands, and one fast falsification test per hypothesis.

// patch safety ladder

Risk-tiered kernel change execution

Every change recommendation comes with an explicit ladder level. No patch reaches production without rollback instructions and monitoring hooks.

L0
Observe only
No system mutation. Read dmesg, journalctl, perf events, tracepoints. Establish baseline evidence before touching anything.
L1
Reproduce and isolate
Reproduce the failure in a safe sandbox — VM, container, or QEMU. Isolate the minimal reproducible case before proposing changes.
L2
Minimal patch + targeted verification
Apply the smallest possible change. Run build checks, targeted boot tests, and unit-level regression verification.
L3
Broader regression and performance checks
Run full regression suites (LTP, kselftest) and performance benchmarks. Confirm no latency, throughput, or stability regressions.
L4
Rollout-ready
Complete rollback plan documented. Observability and alerting hooks in place. Staged rollout strategy defined before production deployment.
// skills/

Three specialized skill modules

Each skill is a structured Markdown module with YAML frontmatter that keeps responses consistent, production-aware, and transferable.

skills/explain-kernel/SKILL.md
explain-kernel
Explains kernel internals in layers: mental model first, then the kernel call path, key structs and APIs, and finally verification commands. Subsystem-native vocabulary — scheduler, mm, vfs, net, block, bpf.
skills/debug-code/SKILL.md
debug-code
Evidence-driven triage workflow. Starts non-destructive: dmesg, strace, bpftrace, perf. Maps every error output to a concrete next action. Never skips interpretation.
skills/setup-env/SKILL.md
setup-env
Profile-based environment bootstrap: fast-lab for speed, repro-lab for reproducibility, incident-lab for forensics. Includes readiness scorecards and cross-contributor consistency checks.
// how to run

Up in three commands

Prerequisite: install and configure gitclaw on your machine.

01
Clone the repository
Get the agent package onto your local machine.
git clone https://github.com/sachindra535/kernel-agent
02
Enter the project
Navigate to the agent root directory.
cd kernel-agent
03
Start the agent
gitclaw picks up agent.yaml automatically.
gitclaw run .
